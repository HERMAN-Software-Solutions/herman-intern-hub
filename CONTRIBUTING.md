# Contributing to HERMAN Intern Hub

Thanks for helping build this. This repo is used both as a production tool and a training ground for HERMAN interns.

---

## Branching

- `main` — production, always deployable
- `dev` — integration branch
- `feat/<short-name>` — new features
- `fix/<short-name>` — bug fixes
