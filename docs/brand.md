# Brand Guide

Extracted from https://herman-software-website.vercel.app

---

## Voice

- **Confident, not arrogant.** "Engineered Software, Measurable Results."
- **Clear, not corporate.** Short sentences. Real outcomes.
- **Collaborative, not preachy.** "You're never in the dark."

## Typography

- Font: Inter (match main site)
- Scale: Tailwind defaults
- Headings: font-semibold, tracking-tight

---

## Components

- Buttons: rounded-lg, px-4 py-2, font-medium
- Cards: rounded-xl, border, shadow-sm
- Inputs: rounded-lg, border-slate-300, focus:ring-2

## Icons

Lucide React (recommended — matches Tailwind ecosystem).

---

## Accessibility

- WCAG AA minimum
- All interactive elements keyboard-accessible
- Alt text on all images
- Color not the sole indicator of state
