# Data Model

PostgreSQL schema for HERMAN Intern Hub (Supabase).

**Version:** 1.1 (approval flow + invitations)
**Last updated:** 2026-09-16

---

## Overview

All tables use `uuid` primary keys generated by `gen_random_uuid()`. Timestamps are `timestamptz` in UTC. Row-Level Security (RLS) is enabled on every table that stores user data.

**Enums are implemented as `TEXT` columns with `CHECK` constraints** for portability and easy migration.

---

## Tables

### `auth.users` (Supabase-managed)
Handles authentication. Never modified directly. Extended by `profiles`.

---

### `profiles`

The core table. One row per user.

```sql
CREATE TABLE profiles (
  id                    UUID PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
  role                  TEXT NOT NULL DEFAULT 'intern'
                        CHECK (role IN ('intern', 'mentor', 'admin', 'super_admin')),
  full_name             TEXT,
  email                 TEXT NOT NULL UNIQUE,
  phone                 TEXT,
  avatar_url            TEXT,
  bio                   TEXT,

  -- Academic
  university            TEXT,
  course                TEXT,
  year_of_study         TEXT,

  -- Internship
  start_date            DATE,
  end_date              DATE,
  mentor_id             UUID REFERENCES profiles(id) ON DELETE SET NULL,
  status                TEXT NOT NULL DEFAULT 'onboarding'
                        CHECK (status IN (
                          'onboarding',   -- accepted invite, wizard in progress
                          'active',       -- full access
                          'paused',       -- temporarily suspended
                          'completed',    -- internship ended normally
                          'withdrawn'     -- left early
                        )),

  -- Approval trail
  invited_via           UUID REFERENCES invitations(id) ON DELETE SET NULL,
  approved_by           UUID REFERENCES profiles(id) ON DELETE SET NULL,
  approved_at           TIMESTAMPTZ,
  mentor_assigned_at    TIMESTAMPTZ,
  agreement_signed_at   TIMESTAMPTZ,
  agreement_version     TEXT,

  -- Directory
  directory_visible     BOOLEAN NOT NULL DEFAULT TRUE,

  created_at            TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at            TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE INDEX idx_profiles_role ON profiles(role);
CREATE INDEX idx_profiles_status ON profiles(status);
CREATE INDEX idx_profiles_mentor ON profiles(mentor_id);
CREATE INDEX idx_profiles_directory ON profiles(directory_visible) WHERE directory_visible = TRUE;
```

### `invitations`

The gatekeeper table. No account is created without an accepted invitation.

```sql
CREATE TABLE invitations (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  email           TEXT NOT NULL,
  token           TEXT NOT NULL UNIQUE DEFAULT encode(gen_random_bytes(32), 'hex'),
  application_id  UUID REFERENCES applications(id) ON DELETE SET NULL,
  invited_by      UUID NOT NULL REFERENCES profiles(id),
  role            TEXT NOT NULL DEFAULT 'intern'
                  CHECK (role IN ('intern', 'mentor', 'admin')),
  status          TEXT NOT NULL DEFAULT 'pending'
                  CHECK (status IN ('pending', 'accepted', 'expired', 'revoked')),
  expires_at      TIMESTAMPTZ NOT NULL DEFAULT (now() + interval '7 days'),
  accepted_at     TIMESTAMPTZ,
  metadata        JSONB NOT NULL DEFAULT '{}'::jsonb,
  created_at      TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE INDEX idx_invitations_token ON invitations(token);
CREATE INDEX idx_invitations_email ON invitations(email);
CREATE INDEX idx_invitations_status ON invitations(status);
CREATE INDEX idx_invitations_expires ON invitations(expires_at) WHERE status = 'pending';
```

### `project_assignments`

Which interns work on which projects.

```sql
CREATE TABLE project_assignments (
  id                     UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  project_id             UUID NOT NULL REFERENCES projects(id) ON DELETE CASCADE,
  intern_id              UUID NOT NULL REFERENCES profiles(id) ON DELETE CASCADE,
  role                   TEXT NOT NULL DEFAULT 'contributor'
                         CHECK (role IN ('lead', 'contributor')),
  compensation_type      TEXT NOT NULL DEFAULT 'unpaid'
                         CHECK (compensation_type IN ('unpaid', 'paid')),
  agreement_document_id  UUID REFERENCES documents(id) ON DELETE SET NULL,
  assigned_at            TIMESTAMPTZ NOT NULL DEFAULT now(),
  UNIQUE (project_id, intern_id)
);

CREATE INDEX idx_pa_project ON project_assignments(project_id);
CREATE INDEX idx_pa_intern ON project_assignments(intern_id);
```

**Rule:** if `compensation_type = 'paid'`, `agreement_document_id` must not be null (enforced by trigger, not CHECK, because it's cross-table).

## Triggers

### Auto-update `updated_at`

```sql
CREATE OR REPLACE FUNCTION set_updated_at()
RETURNS TRIGGER AS $$
BEGIN
  NEW.updated_at = now();
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_profiles_updated
  BEFORE UPDATE ON profiles
  FOR EACH ROW EXECUTE FUNCTION set_updated_at();

CREATE TRIGGER trg_projects_updated
  BEFORE UPDATE ON projects
  FOR EACH ROW EXECUTE FUNCTION set_updated_at();

CREATE TRIGGER trg_tasks_updated
  BEFORE UPDATE ON tasks
  FOR EACH ROW EXECUTE FUNCTION set_updated_at();

CREATE TRIGGER trg_logs_updated
  BEFORE UPDATE ON daily_logs
  FOR EACH ROW EXECUTE FUNCTION set_updated_at();
```

### Auto-activate intern when mentor is assigned

```sql
CREATE OR REPLACE FUNCTION maybe_activate_intern()
RETURNS TRIGGER AS $$
BEGIN
  IF NEW.mentor_id IS NOT NULL
     AND NEW.status = 'onboarding'
     AND NEW.agreement_signed_at IS NOT NULL THEN
    NEW.status := 'active';
    NEW.mentor_assigned_at := now();
  END IF;
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_activate_intern
  BEFORE UPDATE ON profiles
  FOR EACH ROW EXECUTE FUNCTION maybe_activate_intern();
```

### Expire stale invitations

```sql
CREATE OR REPLACE FUNCTION expire_invitations()
RETURNS void AS $$
BEGIN
  UPDATE invitations
  SET status = 'expired'
  WHERE status = 'pending'
    AND expires_at < now();
END;
$$ LANGUAGE plpgsql;

-- Run via pg_cron every hour (Supabase supports pg_cron)
```

### Helper function: current user's role

```sql
CREATE OR REPLACE FUNCTION current_role_name()
RETURNS TEXT AS $$
  SELECT role FROM profiles WHERE id = auth.uid();
$$ LANGUAGE sql STABLE SECURITY DEFINER;
```

### Example policies

**profiles — read own, or admin reads all, or mentor reads assigned:**

```sql
CREATE POLICY "Read own profile"
  ON profiles FOR SELECT
  USING (id = auth.uid());

CREATE POLICY "Admin reads all profiles"
  ON profiles FOR SELECT
  USING (current_role_name() IN ('admin', 'super_admin'));

CREATE POLICY "Mentor reads assigned interns"
  ON profiles FOR SELECT
  USING (
    current_role_name() = 'mentor'
    AND mentor_id = auth.uid()
  );

CREATE POLICY "Update own profile (limited fields)"
  ON profiles FOR UPDATE
  USING (id = auth.uid())
  WITH CHECK (id = auth.uid());
```

**applications — public insert, admin read:**

```sql
CREATE POLICY "Anyone can submit an application"
  ON applications FOR INSERT
  WITH CHECK (TRUE);

CREATE POLICY "Admin reads applications"
  ON applications FOR SELECT
  USING (current_role_name() IN ('admin', 'super_admin'));

CREATE POLICY "Admin updates applications"
  ON applications FOR UPDATE
  USING (current_role_name() IN ('admin', 'super_admin'));
```

**daily_logs — interns CRUD own, mentors read assigned:**

```sql
CREATE POLICY "Intern CRUD own logs"
  ON daily_logs FOR ALL
  USING (intern_id = auth.uid())
  WITH CHECK (intern_id = auth.uid());

CREATE POLICY "Mentor reads assigned interns' logs"
  ON daily_logs FOR SELECT
  USING (
    current_role_name() = 'mentor'
    AND EXISTS (
      SELECT 1 FROM profiles
      WHERE id = daily_logs.intern_id AND mentor_id = auth.uid()
    )
  );

CREATE POLICY "Admin reads all logs"
  ON daily_logs FOR SELECT
  USING (current_role_name() IN ('admin', 'super_admin'));
```

**Block non-active users from most tables:**

Every policy on `projects`, `tasks`, `submissions`, `feedback`, `documents`, `weekly_reports` should include:

```sql
AND EXISTS (
  SELECT 1 FROM profiles
  WHERE id = auth.uid() AND status = 'active'
)
```

**audit_log — admin read only, service_role writes only:**

```sql
CREATE POLICY "Admin reads audit"
  ON audit_log FOR SELECT
  USING (current_role_name() IN ('admin', 'super_admin'));

-- No INSERT policy for regular users — only service_role can write
```

## Notes on Design Choices

- **No `applicants` role in `profiles`** — applications live in their own table until accepted. Keeps `profiles` clean.
- **`invitations` is the single source of truth for access** — no account without a row here.
- **Status enum is on `profiles`, not `auth.users`** — auth stays Supabase-managed.
- **RLS is the last line of defense** — middleware handles UX, RLS handles security.
- **Triggers keep status logic in the DB** — so even direct SQL updates follow the rules.
