# Roadmap

Phased delivery plan for HERMAN Intern Hub.

---

## Phase 1 — MVP (Weeks 1–3)

**Goal:** Replace WhatsApp coordination. Get interns logging work in one place.

- [x] Specification
- [ ] Supabase project setup + schema
- [ ] Auth (intern + admin, email verification)
- [ ] Intern onboarding wizard
- [ ] Intern dashboard (projects, tasks, daily logs)
- [ ] Admin dashboard (manage interns, projects, tasks)
- [ ] Row-level security policies

**Ship criteria:** 5 interns onboarded, logging daily, managed by admin.

---

## Phase 2 — Documents & Reviews (Week 4)

**Goal:** Automate the paperwork.

- [ ] Certificate PDF generation
- [ ] Experience letter PDF generation
- [ ] Mentor feedback on submissions
- [ ] Task approval workflow
- [ ] Weekly report auto-generation + email (Brevo)
- [ ] Document storage + download

**Ship criteria:** Zero manual certificates required.

---

## Phase 3 — Public Presence (Week 5)

**Goal:** Turn the Hub into a recruitment funnel.

- [ ] Public landing page
- [ ] Application form
- [ ] Application review + convert-to-intern flow
- [ ] Public intern directory (opt-in)
- [ ] Success stories page

**Ship criteria:** First 5 applications received via form.

---

## Phase 4 — Expansion (Ongoing)

- [ ] Analytics dashboard
- [ ] Push + email notifications
- [ ] Skills milestones + badges
- [ ] Video submissions
- [ ] Mobile PWA
- [ ] "HERMAN People" — extend to permanent staff
